Know before you hand it over

Each system decides what an app is allowed to hold. Here is where they draw the line.

Windows
  • !The Windows key still opens StartWindows lets no app hold that key, so Sukhi Play closes the menu the moment it appears. You see a flash, nothing more.
  • ✓Everything else holdsTaskbar, Alt+Tab, Alt+F4, Print Screen.
Windows details →
Linux
  • !Wayland sessions keep some keysNo app can hold keys there. Alt+Tab and Super are still switched off on GNOME.
  • !The Snap can’t touch desktop shortcutsWant Alt+Tab locked too? Use the .deb or AppImage.
Linux details →
