Troubleshooting

Something looks wrong on your computer? A short check prints exactly what happened, so it can be fixed.

Locked out right now?

Force Quit always works: Cmd+Option+Esc on a Mac, Ctrl+Alt+Delete on Windows. And if the screen ever fails to appear, Sukhi Play unlocks itself after twelve seconds.

Why this needs the source code

The checks are developer tools that print to a terminal, so they run from the project’s code. About five minutes the first time.

1. Install Node.js

Download the LTS version from nodejs.org and install it like any app.

2. Get the code

Open Terminal (Mac, Linux) or PowerShell (Windows) and run:

git clone https://github.com/meSingh/sukhi-play.git
cd sukhi-play
npm ci

No git? Download the code as a zip, unzip it, open a terminal in that folder and run npm ci.

3. Run the check for your problem

The layout or size looks wrongAll systems
npm run diagnose

Prints the screen and window sizes, then closes. It never locks your screen.

On Linux, if it complains about the sandbox: ./node_modules/.bin/electron . --diagnose --no-sandbox

The taskbar still showsWindows
npm run cover-probe

Tries every way of covering the screen and reports which worked. Your screen is covered for a few seconds.

A key isn’t being heldWindows
npm run key-probe

Lists exactly which keys Windows lets the app hold on your computer.

4. Send the output

Copy everything it printed into a new issue, with what you expected to see.
