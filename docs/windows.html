What it locks down

  • ✓ The whole screen, taskbar included
  • ✓ Alt+Tab, Alt+F4 and the function keys
  • ✓ Print Screen and the Snipping Tool
  • ✓ The magnifier and clipboard history
  • ! The Windows key opens Start, then it is closed again

About that last one

Windows will not hand the Windows key to any app, so pressing it opens the Start menu over Sukhi Play. Holding that key properly would mean a permanent change to your computer, and this app never makes those.

So it does what you would do: it presses Escape. While Sukhi Play is locked it watches for the Start menu, Search and the quick settings panel, closes whichever one appeared, and comes back to the front in about a quarter of a second. Any other window is left alone, so a real dialog never has keys sent into it.

Your child sees the menu flash. They cannot use it.

Antivirus flagged it?

Some antivirus tools quarantine any unsigned app on sight. Check the file’s fingerprint in PowerShell:

Get-FileHash ~\Downloads\Sukhi-Play-Windows-Setup.exe

If it matches the line in SHA256SUMS.txt, it is exactly what was built from the public code.
