SmartScreen is reacting to a new, unfamiliar app, not to anything it found. Making it go away costs hundreds a year, and this app is free.

What it locks down

  • ✓ The whole screen, taskbar included
  • ✓ Alt+Tab, Alt+F4 and the function keys
  • ✓ Print Screen and the Snipping Tool
  • ✓ The magnifier and clipboard history
  • × The Windows key, which Windows keeps

About that last one

Windows won’t hand the Windows key to any app. Pressing it opens the Start menu, and Sukhi Play pulls itself back in front within a tenth of a second. You’ll see a flash.

Taking that key would need a permanent change to your computer. This app never makes those.

Antivirus flagged it?

Some antivirus tools quarantine any unsigned app on sight. Check the file’s fingerprint in PowerShell:

Get-FileHash ~\Downloads\Sukhi-Play-Windows-Setup.exe

If it matches the line in SHA256SUMS.txt, it is exactly what was built from the public code.
