Alt+Tab and the Super key

On Linux those belong to the desktop, not to apps. On GNOME, Sukhi Play switches 25 of them off while it runs and puts every one back when it quits, even after a crash.

Wayland changes this

On a Wayland session, the default on current Ubuntu, no app can catch keys itself. The GNOME switch-off above still works; anything outside it reaches the desktop. For the full lockdown, choose Ubuntu on Xorg at the login screen.

One thing the Snap can’t do

Its restricted permissions are exactly what stop it changing desktop settings, so the Snap leaves those 25 shortcuts alone. Everything else is identical. If that matters, use the .deb or AppImage.
