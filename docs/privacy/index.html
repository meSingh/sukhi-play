Privacy

Two different things: the application you install, and this website. They behave differently, and it is worth being exact about which is which.

The application

It sends nothing anywhere. There is no account, no sign-in, no analytics, no telemetry and no crash reporting. Nothing about what your child does leaves the computer. The list of sites, the play-time limit and every setting live in a file on your own disk.

It makes exactly one request of its own accord: when you press Check for updates, it asks GitHub whether a newer release exists. Nothing is sent with that request beyond what any HTTP request carries, and it happens only when you press the button.

Websites you add are ordinary websites. What they collect is between you and them, which is why every entry in the catalogue links to that site’s own terms.

This website

If you agreed to it, this site uses Google Analytics 4 to count visits and see which pages get read. If you did not, or have not been asked, or have Do Not Track or Global Privacy Control switched on, nothing is loaded from Google at all — not the script, not a cookie, not a request.

When it is on, it records the usual: a page address, a rough location from a truncated IP, a browser and device type, and which site sent you here. Advertising features and ad personalisation are switched off, so nothing is used to build a profile or target anything at you.

Your answer is remembered in your own browser, in localStorage, not in a cookie sent to anyone. Change your mind whenever you like.

Hosting

The site is static files served by GitHub Pages, and downloads come from GitHub Releases. GitHub keeps its own server logs of requests to both, which this project does not control and cannot see. Their privacy statement covers that.

Asking

If something here is unclear or wrong, open an issue and it gets fixed on this page.
